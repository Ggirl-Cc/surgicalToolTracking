\# Surgical Tool Tracking



Training a YOLOv8 model to detect and track surgical instruments in laparoscopic surgery video, using the CholecSeg8k and CholecTrack20 datasets.



\## Goal

Build a model that can identify surgical tools frame-by-frame and track them across a video, including handling occlusion (blood, smoke, overlapping instruments).
